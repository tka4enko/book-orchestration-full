# 📚 BookBot - Интеллектуальный поиск книг

**BookBot** - это мощная система поиска книг с использованием искусственного интеллекта, которая объединяет семантический поиск, BM25 алгоритмы и гибридные методы для точного поиска литературы по различным критериям.

## 🎯 Основные возможности

- **Многоязычный поиск** - поддержка русского, английского, чешского и других языков
- **Гибридный поиск** - комбинация BM25 (ключевые слова) и векторного поиска (семантика)
- **Умная дедупликация** - автоматическое объединение дублирующихся результатов
- **Поиск по ISBN** - точный поиск по международным стандартам книжных номеров
- **Поиск по автору/названию** - быстрый поиск конкретных книг
- **Поиск по жанру/теме** - семантический поиск по содержанию
- **Детекция дубликатов** - предотвращение повторной загрузки книг
- **Веб-интерфейс** - простой и удобный чат-интерфейс

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
# Клонирование репозитория
git clone <repository-url>
cd bookbot_full

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Настройка окружения

Создайте файл `.env` в корневой директории:

```env
# OpenAI API ключи
OPENAI_API_KEY=your_openai_api_key_here

# Модели OpenAI
OPENAI_MODEL_CHAT=gpt-4o-mini
OPENAI_MODEL_EMBED=text-embedding-3-small

# Настройки ChromaDB
CHROMA_DIR=.chroma

# Настройки сервера
HOST=127.0.0.1
PORT=8000

# LangSmith (опционально)
LANGSMITH_TRACING=true
LANGSMITH_PROJECT=bookbot
LANGSMITH_API_KEY=your_langsmith_key
```

### 3. Запуск сервера

```bash
# Запуск FastAPI сервера
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

### 4. Доступ к интерфейсу

Откройте браузер и перейдите по адресу: `http://127.0.0.1:8000`

## 🔍 Алгоритмы поиска

### Гибридный поиск (OptimizedThresholdRetriever)

Система использует многоэтапный подход:

1. **BM25 поиск** - быстрый поиск по ключевым словам
2. **Векторный поиск** - семантический поиск с исключением дубликатов
3. **Умная фильтрация** - настройка порогов по типу запроса
4. **Дедупликация** - объединение результатов по книгам

### Настройки порогов

```python
# Пороги схожести по типам запросов
SIMILARITY_THRESHOLDS = {
    "author": 0.8,        # Высокий порог для точного поиска
    "title": 0.7,         # Средний порог для названий
    "topic": 0.4,         # Низкий порог для тематического поиска
    "free_text": 0.5      # Универсальный порог
}

# Модификаторы для разных языков
LANGUAGE_THRESHOLD_MODIFIERS = {
    "same_language": -0.1,      # Снижение порога для одного языка
    "different_language": 0.0,  # Без изменений для разных языков
    "unknown_language": -0.05   # Небольшое снижение для неизвестного языка
}
```

### Детекция намерений

Система автоматически определяет тип запроса:

- **ISBN** - поиск по номеру книги
- **author_title** - поиск по автору и названию
- **author** - поиск по автору
- **title** - поиск по названию
- **genre** - поиск по жанру
- **topic** - тематический поиск
- **free_text** - свободный поиск

## 📊 Структура данных

### Коллекция "books"
Содержит метаданные книг:
- `title` - название книги
- `author` - автор
- `isbn13` - ISBN-13 номер
- `isbn10` - ISBN-10 номер
- `summary` - краткое описание
- `primary_genre` - основной жанр
- `secondary_genres` - дополнительные жанры
- `language` - язык книги

### Коллекция "content"
Содержит фрагменты текста книг:
- `document_id` - ID книги
- `idx` - индекс фрагмента
- `is_master_chunk` - флаг основного фрагмента
- `title` - название книги
- `author` - автор

## ⚙️ Конфигурация

### Основные настройки (settings.py)

```python
# Размеры чанков для обработки текста
CHUNK_SIZE = 1200          # Размер фрагмента
CHUNK_OVERLAP = 120        # Перекрытие между фрагментами
MAX_CHUNKS = 80           # Максимум фрагментов на книгу

# Параметры поиска
BM25_K = 8                # Количество результатов BM25
VEC_BOOKS_K = 8          # Количество результатов векторного поиска книг
VEC_CONTENT_K = 6        # Количество результатов векторного поиска контента
RRF_K = 60               # Параметр Reciprocal Rank Fusion

# Дедупликация
MAX_CHUNKS_PER_BOOK = 2   # Максимум фрагментов на книгу в результатах
CHUNKS_PER_BOOK_IN_CONTENT = 2  # Фрагментов на книгу в контенте
CONTENT_SEARCH_EXPAND_K = 20    # Расширенный поиск для диверсификации
```

### Переменные окружения

| Переменная | Описание | По умолчанию |

| `OPENAI_API_KEY` | Ключ API OpenAI | - |
| `OPENAI_MODEL_CHAT` | Модель для чата | `gpt-4o-mini` |
| `OPENAI_MODEL_EMBED` | Модель для эмбеддингов | `text-embedding-3-small` |
| `CHROMA_DIR` | Директория ChromaDB | `.chroma` |
| `HOST` | Хост сервера | `127.0.0.1` |
| `PORT` | Порт сервера | `8000` |
| `MAX_CHUNKS_PER_BOOK` | Макс. фрагментов на книгу | `2` |
| `CHUNKS_PER_BOOK_IN_CONTENT` | Фрагментов в контенте | `2` |
